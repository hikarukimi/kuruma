# Web Front UI 设计

## 目标与范围

Web Front 面向警察在电脑端使用，用于查看多个司机发起的事故连接请求，选择其中一路接入，完成实时音视频通话，并按需控制录像。本文仅描述页面布局、显示内容和页面状态。

## 页面结构

```text
登录页
  -> 工作台首页/待处理请求页
  -> 请求详情页
  -> 通话处理页
  -> 通话结束页

辅助入口：
  -> 录像记录页
  -> 系统状态页

异常入口：
  -> 连接失败页
  -> 会话不可接入页
  -> 服务离线页
```

```text
|------------------------------------------------------------|
| 左侧请求队列                         右侧概览              |
| +------------------------------+     +-------------------+ |
| | ACC-20260513-0001            |     | 今日请求          | |
| | 等待接入  00:01:28           |     | 12                | |
| | 司机: 李某  视频             |     +-------------------+ |
| +------------------------------+     +-------------------+ |
| | ACC-20260513-0002            |     | 等待中            | |
| | 等待接入  00:00:42           |     | 4                 | |
| | 司机: 王某  语音             |     +-------------------+ |
| +------------------------------+     +-------------------+ |
| | ACC-20260513-0003            |     | 正在处理          | |
| | 处理中    00:04:10           |     | 1                 | |
| | 司机: 赵某  视频             |     +-------------------+ |
| +------------------------------+                         |
|                                                            |
| 选中请求后在右侧展示详情，双击或点击接入进入请求详情页     |
```

- 顶部登录用户和在线状态。
- 请求状态筛选。

- 事故编号、司机信息、连接类型、等待时长和当前状态。

- 无待处理请求

- 请求列表实时更新

## 3. 请求详情页

用途：警察在接入前确认事故信息、司机信息和设备状态。

```text
+------------------------------------------------------------+
| KURUMA 警察工作台                              返回列表    |
|------------------------------------------------------------|
| 事故详情                                                   |
|                                                            |
| +----------------------------+  +-------------------------+ |
| | 事故编号                   |  | 司机状态                | |
| | ACC-20260513-0001          |  | 定位已获取              | |
| |                            |  | 网络正常                | |
| | 司机                       |  | 摄像头/麦克风可用       | |
| | 李某  138****0001          |  +-------------------------+ |
| |                            |                              |
| | 连接类型                   |  +-------------------------+ |
| | 视频连接                   |  | 事故描述                | |
| |                            |  | 车辆追尾，现场可通行    | |
| | 等待时长                   |  |                         | |
| | 00:01:28                   |  +-------------------------+ |
| +----------------------------+                              |
|                                                            |
| +----------------------------+  +-------------------------+ |
| |          接入处理          |  |        标记暂不接入     | |
| +----------------------------+  +-------------------------+ |
```

- 可接入
- 已被接入
- 已超时
- 已取消

## 4. 通话处理页

用途：警察与司机进行实时通话，并控制当前会话录像。

```text
+------------------------------------------------------------+
| ACC-20260513-0001  通话中  03:25       录像中      返回列表 |
|------------------------------------------------------------|
|                                                            |
| +--------------------------------------+ +---------------+ |
| |                                      | | 会话信息      | |
| |                                      | | 司机: 李某    | |
| |              远端视频画面            | | 电话: 138**** | |
| |                                      | | 位置: 已获取  | |
| |                                      | | 网络: 良好    | |
| |                         +----------+ | +---------------+ |
| |                         | 本地预览 | | +---------------+ |
| |                         |          | | | 事故描述      | |
| |                         +----------+ | | 车辆追尾...   | |
| +--------------------------------------+ +---------------+ |
|                                                            |
| 网络: 良好        司机端: 在线        信令: 已连接          |
|                                                            |
| +--------+  +--------+  +----------+  +----------+          |
| | 静音   |  | 摄像头 |  | 开始录像 |  | 结束通话 |          |
| +--------+  +--------+  +----------+  +----------+          |
+------------------------------------------------------------+
```

控件：

- 静音/取消静音。
- 开启/关闭本地摄像头。
- 开始录像/停止录像。
- 结束通话。
- 返回列表，仅在会话可后台保持时可用。

- 正在接入
- 通话中
- 弱网提示
- 司机端断开
- 信令重连中
- 录像中
- 录像失败
- 通话结束

## 10. 服务离线页

用途：电脑端无法访问后端服务时阻止继续操作，并提示重新检查。

```text
+------------------------------------------------------------+
| 服务离线                                                   |
|------------------------------------------------------------|
|                                                            |
| 当前无法连接到后端服务。                                   |
| 请确认服务已启动，或稍后重试。                             |
|                                                            |
| +----------------------------+                              |
| |          重新检查          |                              |
| +----------------------------+                              |
+------------------------------------------------------------+
```

页面状态：

- 初次检查失败
- 重试中
- 服务恢复

## 页面状态流转

```text
登录页
  -> 工作台首页/待处理请求页
      -> 请求详情页
          -> 通话处理页
              -> 通话结束页
              -> 连接失败页
          -> 会话不可接入页
      -> 录像记录页
      -> 系统状态页
      -> 服务离线页

异常流转：
工作台首页/待处理请求页
  -> 连接失败页
  -> 服务离线页

通话处理页
  -> 通话结束页
  -> 连接失败页
```
