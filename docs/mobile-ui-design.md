# Mobile App UI 设计

## 目标与范围

Mobile App 面向司机使用，用于在事故现场快速发起音视频连接请求、等待警察接入，并完成实时通话。本文仅描述页面布局、显示内容和页面状态。

## 页面结构

```text
启动页
  -> 登录页
  -> 权限检查页
  -> 首页/事故上报页
  -> 等待接入页
  -> 通话页
  -> 通话结束页

异常入口：
  -> 连接失败页
  -> 等待超时页
  -> 权限缺失页
```

## 1. 启动页

用途：检查本地登录态、服务配置和基础初始化状态。

```text
+--------------------------------+
|                                |
|            KURUMA              |
|                                |
|      事故音视频处理系统        |
|                                |
|         正在初始化...          |
|                                |
+--------------------------------+
```

行为：

- 如果已登录，进入权限检查页。
- 如果未登录，进入登录页。

## 2. 登录页

用途：司机登录系统，获取访问令牌。

```text
+--------------------------------+
| 登录                           |
|                                |
| 手机号/账号                    |
| +----------------------------+ |
| |                            | |
| +----------------------------+ |
|                                |
| 密码                           |
| +----------------------------+ |
| |                            | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| |           登录             | |
| +----------------------------+ |
|                                |
| 登录失败时在这里显示错误       |
+--------------------------------+
```

页面状态：

- 输入中
- 提交中
- 登录失败
- 登录成功

## 3. 权限检查页

用途：检查摄像头、麦克风和定位权限。

```text
+--------------------------------+
| 使用前检查                     |
|                                |
| [x] 摄像头权限                 |
| [x] 麦克风权限                 |
| [ ] 定位权限                   |
|                                |
| 事故处理需要采集现场画面、     |
| 声音和定位信息。               |
|                                |
| +----------------------------+ |
| |        授权并继续          | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| |        稍后再说            | |
| +----------------------------+ |
+--------------------------------+
```

行为：

- 权限全部通过后进入首页。
- 任一关键权限被拒绝时进入权限缺失页。

## 4. 首页/事故上报页

用途：司机确认事故信息并发起连接请求。

```text
+--------------------------------+
| 事故连接                       |
|                                |
| 当前状态                       |
| +----------------------------+ |
| | 定位已获取                 | |
| | 网络正常                   | |
| | 摄像头/麦克风可用          | |
| +----------------------------+ |
|                                |
| 事故描述                       |
| +----------------------------+ |
| | 可选，简单描述现场情况     | |
| |                            | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| |       发起视频连接         | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| |       仅发起语音连接       | |
| +----------------------------+ |
+--------------------------------+
```

页面内容：

- 定位状态。
- 网络状态。
- 摄像头和麦克风状态。
- 事故描述输入框。
- 视频连接按钮。
- 语音连接按钮。

状态：

- 可发起
- 定位获取中
- 请求提交中
- 请求提交失败

## 5. 等待接入页

用途：司机发起请求后等待警察接入。

```text
+--------------------------------+
| 等待警察接入                   |
|                                |
| 事故编号                       |
| ACC-20260513-0001              |
|                                |
| +----------------------------+ |
| |          等待中            | |
| |        00:01:28            | |
| +----------------------------+ |
|                                |
| 已提交现场位置和连接请求       |
| 请保持 App 打开并等待接入      |
|                                |
| +----------------------------+ |
| |         取消请求           | |
| +----------------------------+ |
+--------------------------------+
```

页面状态：

- 等待接入。
- 已接入。
- 等待超时。
- 已取消。
- 已结束。

## 6. 通话页

用途：司机与警察进行实时通话。

```text
+--------------------------------+
| 警察处理中              录制中 |
|--------------------------------|
|                                |
|                                |
|          远端视频画面          |
|                                |
|                                |
|                    +---------+ |
|                    | 本地预览 | |
|                    |         | |
|                    +---------+ |
|                                |
|--------------------------------|
| 网络: 良好        通话 03:25   |
|                                |
| +------+  +------+  +--------+ |
| | 静音 |  | 摄像 |  | 结束   | |
| +------+  +------+  +--------+ |
+--------------------------------+
```

控件：

- 静音/取消静音。
- 开启/关闭摄像头。
- 结束通话。
- 显示录像状态，但司机端不控制录像。

状态：

- 连接中
- 通话中
- 弱网提示
- 对端断开
- 录像中
- 通话结束

| +----------------------------+ |
+--------------------------------+
```

用途：提示司机补齐关键权限。

| +----------------------------+ |
|                                |

+--------------------------------+
```

## 页面状态流转

```text
启动页
  -> 登录页
  -> 权限检查页
  -> 首页/事故上报页
  -> 等待接入页
      -> 通话页
      -> 等待超时页
      -> 连接失败页
      -> 首页/事故上报页
  -> 通话页
      -> 通话结束页
      -> 连接失败页
```
